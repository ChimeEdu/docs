If you teach the same course to several classes, you don't need a copy of each activity for every period. Link one activity to as many of your classrooms as you like. It stays **one activity**: edit it once and every class sees the change, and it counts **once** toward your plan's activity limit.

This works for every activity type: quizzes, maps, timelines, flash cards, fill-in-the-blank, Graphs & Charts, and diagrams. There's no extra plan requirement; you just need more than one classroom. Assessments, study guides, and Experiences could already be linked to several classrooms, and they work as before.

## What's shared and what each class gets

| The same in every class | Separate for each class |
| --- | --- |
| The content: questions, pins you place, events, cards, passages, data, and settings | **Dates**: when it opens and, if it's graded, when it's due. See [Set Dates by Class](/teachers/activities/per-class-dates) |
| Whether it's graded, and how grades display | Its students' work: per-student copies, groups, and submissions |
| How students work on it (One shared, Per-Student, or Group Assignment) | On a shared map, the pins its students add. See [Class Layers on Shared Maps](/teachers/activities/map-class-layers) |
| The activity password | On Compass and Pie charts, and Scatter charts that collect data, the class results |
| | A column in that class's gradebook, and its own classroom page link |

## Add an activity to several classes

<Tabs>
  <Tab title="When you create it">
    The **Classrooms** list on the create page is a checklist. Tick every class the activity is for. The first class you tick becomes the **home class** and shows a **Home** label; choose **Make home** on another ticked class to change it.
  </Tab>
  <Tab title="An existing activity">
    Open the activity, go to **Students**, and use the **Classrooms** checklist in the first card (**Classroom**, or **Classroom & copies** for activities that can be issued). Each tick saves straight away.
  </Tab>
  <Tab title="Many activities at once">
    On your Activities list, select the activities, then choose **Add to…** or **Remove from…** in the bar that appears, and tick the classes. You can change up to 100 activities at a time. When it's done, a message tells you how many changed, how many were already there, and which couldn't be changed and why.

    **Move to classroom** is different: it takes the activity out of all its classes and puts it in the one you pick.
  </Tab>
</Tabs>

A class you add starts with the home class's dates. You can change them under **Students › When**.

You can also have **Create with AI** add a new activity to several classes. See [Creation Assistant](/teachers/ai/creation-assistant).

<Note>
  On a **shared map** that already has pins, adding a second class can open a dialog that asks who should see each existing pin. See [Class Layers on Shared Maps](/teachers/activities/map-class-layers).
</Note>

## The home class

One of the activity's classes is its **home class** (some screens call it the *main class*). It matters in a few places:

- **Duplicates** go into the home class only. See [Duplicating](#duplicating) below.
- **Students in two of your classes** count in the home class when they're in it. See [Students in two of your classes](#students-in-two-of-your-classes).
- **If you remove the home class**, the earliest of the remaining classes becomes home.
- **If you archive the home class**, the home moves to the earliest of the activity's other classes that's still active, along with that class's dates. Restoring the archived class doesn't move it back.

## Sharing links

Under **Share**, **Classroom page links** lists one link for each class. Each one opens the activity on that class's classroom page. Someone who opens the activity from a class's link sees that class's dates. The link of an archived class won't open until you restore the class.

## Removing a class

Untick the class in the **Classrooms** checklist, or use **Remove from…** on your Activities list.

If students in that class have already started work, you're asked first, and the dialog says how much work there is. Their work isn't deleted: it's kept with the activity, and it comes back if you add the class again. Students who are also in another of the activity's classes keep working there.

If the class is the activity's **only** class, the dialog suggests **Move to another class instead**, because moving keeps every student's work with the activity. **Remove anyway** leaves the work behind until you add that class back.

## Students in two of your classes

A student who's enrolled in two or more of the activity's classes sees it **once**, on their dashboard, under one class. They count in that class:

- the home class, if they're in it;
- otherwise, the first of their classes you added to the activity.

Their dates, their status, and any "Now open" notice come from that class.

On a Per-Student or Group Assignment activity, you can change the class a student counts in with **Counts in** on the roster. See [Per-Student & Groups](/teachers/activities/issuance#activities-in-several-classes).

## Passwords

An activity password is **one password for the activity**. It's asked on every class's link and on the activity's own link. Everyone except you needs it, your students too. Once someone enters it, the activity stays open in that browser tab.

A map's **Student Mode password** works differently: it's for people outside the map's classes, and your students never need it. See [Maps](/teachers/activities/maps#let-students-add-their-own-pins).

## Duplicating

When you duplicate an activity that's in several classes, the copy goes into the **home class only** and starts with no dates. The message after duplicating says so. Add more classes from the copy's **Students** section.

When you duplicate a **map** that has pins your students or visitors added, ChimeEdu asks **What should the copy include?**

| Choice | What the copy gets |
| --- | --- |
| **My pins only** (selected for you) | The pins you added, including older pins with no author name or with your own name. Students start with a clean map |
| **Student pins only** | Just the pins your students and visitors added |
| **Both** | Everything on the map, as it is now |
| **Neither (an empty map)** | The map and its settings, with no pins at all |

This happens on maps in one class too. A map with only your own pins duplicates straight away.

On a map with class layers, the copy only takes pins that every class sees. Pins you've kept in one class, each class's own pins, and visitors' pins stay with the original.

A copy from your institution's library is a separate case. See [Institution Library](/teachers/institution-library).

## Things that stay single-class

- **Quick (temporary) activities** can only be in one class.
- You can only add **classrooms you own**, and not archived classrooms.
- An **archived activity** has to be restored before you can change its classes.

## Common questions

<AccordionGroup>
  <Accordion title="Why can't I tick a second class?">
    The checklist says why under the list. The usual reasons are that the activity is a Quick (temporary) activity, which stays in one class, or that the activity is archived. Restore an archived activity first.
  </Accordion>

  <Accordion title="Does adding a class notify its students?">
    No. If the activity is already open, the new class's students simply find it on their dashboard and classroom page. If you give that class a later opening time, its students get a "Now open" notice when it opens. See [Set Dates by Class](/teachers/activities/per-class-dates#notices-when-a-class-opens).
  </Accordion>

  <Accordion title="Does an activity in three classes count three times toward my plan?">
    No. It's one activity, so it counts once.
  </Accordion>

  <Accordion title="Can students in one class see another class's work?">
    No. Each class's students see their own work and, where the activity shares results, their own class's results. Your own content is the same for everyone.
  </Accordion>

  <Accordion title="What happens if I archive one of the classes?">
    The activity stays open in its other classes. Only an activity whose last active class is archived goes into your Archived list with it. See [Archive and Restore a Classroom](/teachers/classrooms/archive-a-classroom).
  </Accordion>
</AccordionGroup>
