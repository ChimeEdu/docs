Map activities anchor knowledge to real places. You set a base map, choose the default view and zoom level, place pins anywhere on the globe, and students explore the content at their own pace — opening pin cards to read descriptions, view images, and build the spatial understanding that a textbook passage simply cannot provide.

## Creating a Map Activity

<Steps>
  <Step title="Open New Activity">
    From your teacher dashboard, click **New Activity** and select **Map**.
  </Step>
  <Step title="Set the default view">
    Search for a location or drag the map to the area your activity covers. Set the default zoom level so students open the activity with the right geographic context already in view.
  </Step>
  <Step title="Add pins">
    Click anywhere on the map to drop a pin. Reposition it by dragging, or delete it and start again — pins are fully editable at any time.
  </Step>
  <Step title="Fill in each pin card">
    For every pin, add a **title**, a **description** (formatted text is supported), and one or more **images**. The more context you provide, the richer the student experience.
  </Step>
  <Step title="Save the map">
    The classroom is chosen from a dropdown when you create the activity — there is no separate publish step. The map is available to that classroom straight away, and pins you add or edit are live as you save them.
  </Step>
</Steps>

<Tip>
  Use the list-view alternative in the activity settings to offer a keyboard- and accessibility-friendly version of the same content. Students who find map navigation difficult can read all pin cards in a structured list without missing any information.
</Tip>

## Pin pages and the Mini Timeline

Each pin's card can be organized into **pages** — a shared template that applies to every pin in the map, so all your pins follow the same structure. Set the pages up from **Map Settings** on the activity page, or from the **Pages** button in Teacher Mode on the canvas — and you can do it _before_ placing a single pin, so you never have to create a throwaway pin just to define the structure.

One of the page types is the **Mini Timeline** — a compact, in-pin timeline of up to **five** dated entries. Each entry has a title, a date (and an optional time), and a short description you can make **bold**, _italic_, or underlined. Entries are ordered by date by default; turn on **Allow manual ordering** for the page to drag them into any order instead. When reading, students can flip the timeline between a **vertical** and **horizontal** layout.

## What Students Experience

When a student opens a Map Activity, they land on the default view you configured. From there they can:

- **Pan and zoom** freely to any part of the map.
- **Click any pin** to open the full pin card with your title, description, and images.
- **Navigate between pins** using the list-view mode for a more linear, accessible experience.

Students move at their own pace. There is no timer and no set order — the activity is designed for independent exploration.

<Note>
  Keyboard navigation between pins works on standard geographic maps. On maps that use a custom **image or SVG background**, the pins can't currently be reached by keyboard — for those, the **list view** is the accessible route, and it carries exactly the same pin content. If you build an image-based map, mention list view to your students.
</Note>

## Give each student their own map

By default a map is one artifact your whole class shares. On Plus and Premium you can issue it **per student** — every student builds their own map, with your pins showing as a locked starting layer — or by **group**, where students placed into groups (A–Z) co-edit one map together. A **Students** panel on the activity page tracks who has started work.

See [Per-Student & Groups](/teachers/activities/issuance) for the full walkthrough.
