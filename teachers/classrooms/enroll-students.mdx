Enrollment on ChimeEdu runs on a **classroom code**: an 8-character code unique to each classroom. Students enter it either when they create their account or from their dashboard afterwards.

## Finding your classroom code

Open the classroom and look for the **Share with Students** card. It gives you:

* The **Classroom Code** itself, with **Copy Code**
* **Copy Link** — a sign-up link with the code already filled in, for students who don't have an account yet
* A **QR code** to project or print
* **Regenerate**, if you ever need to retire a code

<Warning>
  Regenerating replaces the code immediately. Students already enrolled stay enrolled, but the old code stops working — so anyone who hasn't joined yet will need the new one.
</Warning>

## How students join

Which route a student takes depends on whether they already have an account.

<CardGroup cols={2}>
  <Card title="New students" icon="user-plus">
    Send them the **link** (or the QR code). It opens the sign-up page with your classroom code pre-filled — when they finish creating their account, they're enrolled automatically.
  </Card>

  <Card title="Students who already have an account" icon="user-check">
    Send them the **code**. They sign in, then enter it in the **Join** form on their student dashboard.
  </Card>
</CardGroup>

<Note>
  The sign-up link only enrolls students during account creation. A student who already has a ChimeEdu account can't join by clicking it — they need the code itself. When in doubt, share both.
</Note>

Students need a ChimeEdu account to enroll, and there's no approval step: once they enter a valid code they're in, and your classroom content is immediately available to them.

## Email invitations

You can also invite students by email from the classroom — up to 20 addresses at a time. Each invitation links to the sign-up page with your code attached and expires after **7 days**.

## What students see once they've joined

Your classroom page, listing everything you've linked to it: activities (quizzes, maps, timelines, flash cards, fill-in-the-blank), assessments, study guides, and Experiences. Content is grouped into tabs and shown newest first, and students can search and sort it themselves.

<Note>
  A couple of things worth knowing about visibility. Classroom content sits on a public URL, so enrollment governs what appears on a student's dashboard rather than who is technically able to open the page — assessment passwords and guide passwords are the real access controls. And Experiences set to **restricted** don't appear in the classroom listing at all; share those directly.
</Note>

## Tracking participation

The classroom shows your enrolled students, and for **assessments** you can see submissions and open each one. Other activity types don't report completion — quizzes in particular save nothing after the session ends.

## Frequently asked

<AccordionGroup>
  <Accordion title="Do students need an account for everything?">
    No. Live quizzes and quick activities can be joined by anyone with the 6-character Quiz ID, no account required. Classrooms, assessments, and saved flash card progress do need one.
  </Accordion>

  <Accordion title="Can a student be in more than one of my classrooms?">
    Yes. Students can be enrolled in any number of classrooms — they just enter each classroom's code.
  </Accordion>

  <Accordion title="A student says the code doesn't work.">
    Check they're using the 8-character **classroom** code and not a 6-character Quiz ID, that they've typed it exactly, and that the code hasn't been regenerated since you shared it.
  </Accordion>

  <Accordion title="Can I remove a student later?">
    Yes — manage enrolled students from the classroom's student list.
  </Accordion>
</AccordionGroup>
