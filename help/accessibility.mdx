ChimeEdu is built to be usable by every student and teacher, regardless of how they interact with a computer. This page describes the accessibility features available in the platform, how to use them, and what to do if you run into a barrier.

## Keyboard Navigation

Every activity and page in ChimeEdu can be used without a mouse. You can navigate the entire platform using only a keyboard:

- **Tab** moves forward through interactive elements; **Shift + Tab** moves backward.
- A **skip-to-main-content link** appears when you press Tab on any page — use it to jump past the navigation and straight to the page content.
- All menus, dropdowns, and dialogs follow standard keyboard patterns: **Arrow keys** to move between options, **Enter** to select, and **Escape** to close and return focus to where you were.
- **Map activities** include a **List View** toggle that gives you a keyboard-friendly list of all map pins — no mouse or trackpad required. Look for the "List View" button near the top of the map.

## Screen Reader Support

ChimeEdu is tested with screen readers on every release. Supported combinations include:

- **NVDA** with Firefox or Chrome on Windows
- **VoiceOver** with Safari on macOS and iOS

All form fields have visible labels, error messages are announced automatically, and page titles update as you navigate so you always know where you are in the app.

## Display and Visual Preferences

### Dark Mode

ChimeEdu includes a platform-wide **dark mode** with sufficient color contrast on all text and interactive elements. Switch between Light, Dark, and System (follows your OS setting) from the theme menu in the navigation bar.

### Reduced Motion

If you have **reduced motion** enabled in your operating system or browser settings, ChimeEdu will automatically disable non-essential animations — including quiz celebration effects. No configuration inside the app is required.

### Text Size and Zoom

The platform supports **200% browser zoom** without content being cut off or requiring horizontal scrolling (except for maps and data tables, which are inherently two-dimensional). All text scales with your browser's font size preferences.

### OpenDyslexic Font

**Study Guides** offer an **OpenDyslexic** font option to support readers with dyslexia. Look for the font toggle within a Study Guide activity.

## Timed Activities and Accommodations

Teachers can enable **extended time** for individual students on quizzes and assessments. This is designed to support students with IEPs, 504 plans, or other documented accommodation needs — no extra steps required from the student once the teacher has set it up.

To enable extended time for a student (teachers):

1. Open your classroom from the dashboard.
2. Go to the **Roster** tab and find the student.
3. Enable the **Extended Time** toggle for that student.

Once enabled, that student's timers will automatically be extended on all timed quizzes and assessments in your classroom.

## Alt Text for Images

All image surfaces across ChimeEdu support **author-provided alt text**, including flash cards, assessment images, activity covers, study guides, timeline events, experience locations, and map pins. When adding an image to any of these areas, you'll see an alt text field — filling it in ensures screen reader users get a meaningful description of the image.

## Supported Browsers and Devices

ChimeEdu works on all modern browsers and devices:

| Category | Supported |
|---|---|
| **Browsers** | Latest two major versions of Chrome, Firefox, Safari (macOS & iOS), Microsoft Edge |
| **Screen readers** | NVDA + Firefox/Chrome (Windows); VoiceOver + Safari (macOS, iOS) |
| **Operating systems** | Windows, macOS, iPadOS, iOS, ChromeOS, Android |
| **Input methods** | Mouse, keyboard, touch, and voice control |

<Note>
  Internet Explorer is not supported. If you're using IE, please switch to a modern browser for the best experience.
</Note>

## Known Limitations

ChimeEdu is **partially conformant** with WCAG 2.1 Level AA. The following limitations are present in the current version:

- **Non-English text passages** — the content editor does not yet provide a way to mark non-English passages so screen readers can pronounce them correctly. This will be addressed in a future update.
- **Some small icon buttons** on mobile (such as the notification bell) may be slightly below the recommended minimum touch target size. This is being improved.

## Report an Accessibility Issue

If you run into an accessibility barrier on ChimeEdu, please let us know. We aim to respond to all accessibility inquiries within **5 business days**.

<CardGroup cols={2}>
  <Card title="Email the Accessibility Team" icon="envelope" href="mailto:accessibility@chimeedu.com">
    Send a message to **accessibility@chimeedu.com** with a description of the barrier you encountered.
  </Card>
  <Card title="Use the Contact Form" icon="message" href="https://app.chimeedu.com/contact">
    Fill out the contact form at app.chimeedu.com/contact — please mention **"accessibility"** in the subject line.
  </Card>
</CardGroup>

When reporting a barrier, it helps to include:

- The **page URL** where the issue occurred
- A **brief description** of what you were trying to do
- The **browser and assistive technology** you were using (if any)
- What happened — or what didn't happen — as a result

Screenshots are welcome but not required.
