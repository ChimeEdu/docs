## v0.9.2 — Daystrom

**June 3, 2026**

**Added**
- **Platform Search** — A new search experience across every classroom, activity, assessment, study guide, experience, student roster, and Knowledge Base article you own or have access to. Available from the dashboard hero bar, the top-nav mini search, and a full `/search` results page with type and classroom filters.
- **Live Search Indexing** — Content you create, rename, or delete appears in search results within seconds — no manual reindex required.
- **Dashboard Hero Search** — Instant results grouped by type with quick-filter tabs (Classrooms, Activities, Learning Tools, Students, Actions, Help).

**Changed**
- Dashboard welcome layout now displays as a single greeting line with improved spacing.
- Type accent colours (classrooms coral, activities green, assessments yellow, study guides purple, experiences blue) are now consistent across search results, dashboard, and the Features mega menu.
- Privacy Policy updated to reflect new search infrastructure.

**Fixed**
- Students enrolled in multiple classrooms now appear as a single search result listing all their classrooms, instead of once per enrolment.
- Layout overflow bug resolved for search results and dashboard activity cards under long titles.

## v0.9.1 — Daystrom

**April 29, 2026**

**Added**
- **Accessibility Conformance Report** — New `/accessibility` page publishes the public VPAT 2.5 Rev WCAG report.
- **Map Activity** — Keyboard and on-screen-button controls for moving pins (Teacher Mode) and panning the map, as accessible alternatives to mouse-drag. Includes screen-reader announcements after each move.
- **Timeline PDF Export** — Server-side rendered with full PDF/UA-1 tagging: selectable text, real heading structure, alt text, and document title in metadata.
- **Form autocomplete** — Sign-up form now supports browser autofill for email, name, password, and organisation fields.

**Changed**
- Theme switcher now uses consistent sun / moon / half-circle iconography across every theme menu.
- Touch targets (notification bell, per-notification delete controls) enlarged for easier tapping on mobile.
- Browser tabs now show route-specific page titles (e.g. "ChimeEdu ∙ Classrooms") on every page.

**Fixed**
- Theme menu label and screen reader announcement now stay in sync when switching between Light / Dark / System.
- Theme menu trigger correctly linked to its menu for assistive technology users.

## v0.9.0 — Daystrom

**April 6, 2026**

**Added**
- **Fill-in-the-Blank Activity Type** — Rich text passage authoring with inline blanks, auto-grading, hints, and answer variants. Includes a public player and landing page.

- Transactional email templates redesigned with branded styling.

**Fixed**
- Fill-in-the-Blank field naming inconsistencies resolved.
- Dashboard layout regressions in hero grid and flex containers fixed.

## v0.8.0 — Daystrom
